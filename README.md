# PTCG Vision — 用真實的寶可夢卡跟電腦對戰

 Tech Stack: Python 3.12 · OpenCV · WebSocket · 原生 HTML/CSS/JS · Docker · Playwright



### 🔧 技術亮點

- 瀏覽器當感測器、Docker 當運算:瀏覽器以 getUserMedia 取相機影像,經 WebSocket 傳入容器運算、回傳遊戲狀態(解決 Windows Docker 取不到 USB 相機的問題)。

- 卡片辨識(OpenCV):輪廓偵測 + 透視校正,圖案卡以 ORB + FLANN + RANSAC 特徵比對;設計「剔除共同版型特徵 / 幾何合理性 / 明顯勝出」三道防誤判機制 → 單張畫面 93.5% 正確、0 誤判。

- 動作判斷:去抖動狀態機將「每區看到的卡」轉為玩家動作(放置 / 進化 / 貼能量 / 撤退);疊歪辨識率 39% → 93%。

- 規則引擎 + 電腦 AI:資料驅動(JSON 指令,約 35 種 op)的卡片效果引擎 + 貪婪評分式 AI。

- 測試:合成影像、模擬序列、自我對戰 300 局、Chromium 假相機 + Playwright 四層端對端測試。

目標：外接相機從正上方拍桌面，即時認出每一張卡是什麼。
這是「真實卡片 vs 電腦對戰」的第一步，之後的分區偵測、規則引擎、電腦 AI 都建立在這上面。

## 架構：辨識在 Docker、相機在瀏覽器

Windows 上的 Docker 拿不到 USB 相機，所以分工如下：

```
外接相機 ──► 瀏覽器（開相機、選鏡頭、畫框框）
                 │  每張畫面用 WebSocket 傳過去
                 ▼
          Docker 容器（Python + OpenCV：找卡、辨識）
                 │  傳回「哪裡有卡、是哪一張」
                 ▼
             瀏覽器把結果畫在畫面上
```

## 啟動

```bat
cd ptcg-vision
docker compose up -d --build
```

瀏覽器打開 **http://localhost:8765**，按「開啟相機」，瀏覽器會問是否允許使用相機。
外接相機請在左上角的選單切換（之後會記住）。

> 一定要用 `localhost` 開：瀏覽器只允許 `localhost` 或 HTTPS 網址使用相機。
> 註冊的卡片存在 `ptcg-vision/db/` 資料夾，重建容器也不會不見。

## 拍攝環境（影響準確度最大）

* 相機**正上方往下拍**：手機支架、檯燈夾、懸臂支架都可以。斜拍也行，但越正越準。
* **深色素面桌墊**：黑色桌布、深色滑鼠墊。卡片有黃邊，深色背景最好找邊框。
* 光線均勻、**避免反光**：不要讓燈直接照在卡面上，閃卡尤其容易反光。
* 卡片之間留一點空隙，不要重疊（重疊會在第 2 階段處理）。
* 解析度選 720p 就夠；卡片太小認不出來時再改 1080p。

## 步驟 1：註冊你的兩副牌組（右側「① 註冊」）

1. 放一張卡到畫面中，黃色框會框住它，右側出現拉正後的預覽。
2. 輸入卡名（例：`火紅不倒翁`）、選種類、牌組名稱（`火牌組` / `草牌組`）、在牌組裡有幾張，按 **Enter**。

   * 種類照官方分類：**寶可夢**／訓練家（**物品**、**寶可夢道具**、**支援者**、**競技場**）／**基本能量**、**特殊能量**。
這個分類第 3 階段的規則引擎會用到（例如支援者每回合只能用 1 張、寶可夢道具要掛在寶可夢身上）。
   * 卡名結尾是「能量」會自動判斷：「基本火能量」→ 基本能量，其他 →特殊能量；「能量回收」這種物品卡不會被誤判。
   * 牌組名稱會沿用上一次的，連續註冊同一副牌很快。
3. **同一種卡只需要註冊 1 次**（4 張一樣的卡，張數填 4）。
預覽旁邊會提示「這張看起來已經註冊為 ○○」，避免重複。
某張卡常常認不出來時，換個角度再註冊一次並輸入**一樣的卡名**，等於幫它多加一張照片。
4. 也可以用手機拍好照片，檔名取成卡名（`火紅不倒翁.jpg`），在「或用照片批次匯入」一次選多張。
5. 「③ 卡表」可以檢查每副是不是剛好 **60 張**（並顯示寶可夢／訓練家／能量各幾張）、
直接改種類、調整張數、刪除，並匯出 `decklist.csv`（Excel 可直接開）。

> 你的 V 起始牌組約有 26 張道具／支援者是隨機的，網路查不到你手上的確切卡表，
> 所以這一步同時也是在建立你的真實卡表，第 3 階段寫卡片效果時會用到。

## 步驟 2：測試辨識（右側「② 辨識」）

把幾張卡放到桌上，每張卡上會顯示卡名與信心度：

* 🟩 綠框 + 卡名：認出來了
* 🟥 紅框「？認不出 / 未註冊」：沒註冊過，或角度／反光讓它認不出來。**系統寧可說認不出，也不會亂猜。**

可以試試：轉方向、放顛倒、斜一點、移動位置、同時放 6 張以上、拿一張沒註冊的卡。
勾選「顯示辨識細節」可以看到每張卡的判斷依據（調整燈光時有用）。

## 辨識原理

1. **找卡片**：邊緣偵測找出長寬比接近 63:88 的四邊形，透視校正拉成直的。
2. **比對**：

   * 圖案豐富的卡（寶可夢、訓練家）：ORB 特徵點 → FLANN 索引找候選 → RANSAC 幾何驗證。
   * 圖案單純的卡（基本能量）：感知雜湊 + 顏色分佈。
3. **防誤判（三道）**：

   * **剔除版型**：所有卡共用的黃框、名字列、HP、招式框，在每張卡的同一位置都長得一樣，
建索引時會自動找出這些「大家都有」的特徵點並排除，只用每張卡獨有的插圖與文字比對。
   * **幾何合理性**：兩張卡都已拉正，同一張卡的對應只可能是「幾乎不動」或「轉 180 度」；
重複文字（招式說明到處都有「傷害」「能量」）造成的退化對應會被擋掉。
   * **明顯勝出**：第一名必須遠勝第二名才算認出。
4. **穩定**：同一張卡連續看好幾格畫面再投票；已穩定認出的卡每 2 秒複查一次，運算留給新放上桌的卡。

## 第 2 階段：④ 對戰墊（判斷你做了什麼動作）

沒有印表機也可以：對戰墊是**畫在螢幕上的虛擬區域**。

1. 切到「④ 對戰墊」，按「✏️ 調整區域」，在畫面上拖曳框框、拉右下角改大小，
讓每一區對齊你桌墊上想放卡的位置，按「💾 儲存區域」（存在 `db/zones.json`）。
想要桌上有記號，可以用紙膠帶或便利貼標出每一區。
2. 照下面的方式出牌，右側會即時顯示「我的場面」和「動作紀錄」：

|動作|怎麼做|
|-|-|
|放寶可夢|放進戰鬥場或備戰區|
|進化|進化卡直接疊在原本的寶可夢上|
|貼能量／寶可夢道具|先疊在寶可夢**上面**停約 1 秒讓相機看到，再塞到下面|
|使用訓練家卡|放到「訓練家出牌區」（系統顯示效果，之後移到棄牌區）|
|撤退／交換|直接把兩隻寶可夢換位置（能量會跟著走）。從戰鬥場退下的寶可夢會依**撤退數**扣能量：種類一樣自動扣，不一樣就在右側點選要丟哪幾張；剛用「寶可夢交替」則不扣|
|寶可夢氣絕／收回|從場上拿走，約 4 秒沒出現在別格就算離場|

防誤判：卡片要穩定約 0.8 秒才算「出現」、區域空掉 1.5 秒才算「離開」；
手移動途中看不清楚時一律維持原判斷。
**疊歪也沒關係**：找不到完整卡片輪廓時，系統會 (1) 跟「疊上去之前」的畫面比對找出新卡、
(2) 直接在區域裡比對特徵點，找出被遮最少、也就是最上面那張。
桌墊是暗的，所以區域裡還有亮的東西（卡片、手）時不會誤判成「空了」；
就算真的誤判，接著出現能量或進化卡時也會自動把原本的寶可夢接回來。
**一張卡只算一格**：卡片放歪壓到隔壁格、或兩張相鄰的卡碰在一起時，以卡片「中心點」在哪一格為準；
中心落在兩格之間的縫隙就算最近的那一格。
**自動校正**：相機穩定看到的寶可夢跟右邊紀錄不一樣超過 2.5 秒，就以相機為準修正（紀錄裡會標 🔧）。
判斷錯了按 **↶ 復原**（或鍵盤 Z）回到上一步；按過復原的格子不會被自動校正改回去。放錯（例如進化卡直接放到場上、能量放在空格、
不能進化的組合、寶可夢放到訓練家區）會跳出 ⚠ 提醒。

## 第 3 階段：⑤ 對戰（你用實體卡，電腦在螢幕上）

### 開一局

1. 先到「④ 對戰墊」把區域對好，桌上的卡收起來。
2. 切到「⑤ 對戰」，選電腦要用哪一副（你用另一副實體牌組），按 **🎮 開始新對戰**。
3. 照右邊「👉 請你動手」做：洗牌抽 7 張、把基礎寶可夢**正面朝上**放到戰鬥場／備戰區、拿 6 張獎賞卡。
手牌沒有基礎寶可夢就按「我重抽了」（電腦會多抽 1 張）。電腦也會自己擺好（開始後才翻開）。
4. 按 **開始對戰（擲硬幣）**。

### 對戰畫面

切到「⑤ 對戰」後，左邊變成整個對戰場地（仿手機遊戲 Pokémon TCG Pocket 的風格）：

* **上半是電腦、下半是你**：戰鬥場在中間、備戰區在外側，每張寶可夢都用你拍的高畫質卡圖顯示，
下方白色標籤是**剩餘 HP**（受傷變黃、快倒變紅），左邊圓圈是身上的能量，右上角是特殊狀態。
* 電腦那一排上方：**棄牌區**（最上面那張＋張數）、**牌庫張數**、**獎賞卡**、**手牌**（卡背＋張數）。
點棄牌區可以看電腦丟掉的所有卡。
* **點任何一張卡**＝放大：大卡圖＋HP、能量、狀態、進化過程、招式說明、弱點／抵抗力／撤退。
點你自己的戰鬥寶可夢，還可以直接在放大畫面按招式攻擊。
* **動畫**：攻擊時寶可夢衝出去、受傷的卡會晃動並跳出「-90」、氣絕變灰、擲硬幣會轉、
電腦使用訓練家卡時卡片會放大秀出來再飛進棄牌區；**暗影爪丟掉電腦手牌**時，也會秀出被丟掉的是哪張卡，
手牌張數跟著減少、棄牌區跟著增加。
* 電腦的回合會一步一步重播（場面跟著紀錄一起變），看得出它做了什麼。
* 相機畫面縮到**右下角**；點一下可以放大（調整卡片位置時用），再點一下縮回去。

卡圖在 `static/cards/`（從你拍的 7 張照片裁切、拉正，52 種卡都有）。

### 你的回合

|你要做的|怎麼做|
|-|-|
|放寶可夢、進化、貼能量、用訓練家卡、撤退|跟「④ 對戰墊」一樣，在桌上做，相機會判斷|
|攻擊|按右邊的招式按鈕，或鍵盤 <kbd>1</kbd>／<kbd>2</kbd>|
|結束回合|按「結束回合」或 <kbd>空白鍵</kbd>|
|判斷錯了|<kbd>Z</kbd> 或「↶ 復原」（傷害、特殊狀態不會被復原掉）|
|抽牌、找牌、拿獎賞卡、丟棄|實體卡你自己動手，系統會列在「👉 請你動手」，做完可以按 ✓|

系統會檢查規則並提醒你（⚠）：先攻第一回合不能攻擊／用支援者、每回合 1 張能量、1 張支援者、1 次撤退、
第一回合不能進化、剛放上場的不能進化、睡眠／麻痺不能撤退、奇巴納的使用條件等。

### 自動計算

* **傷害**：招式基本傷害 → 攻擊方效果（叫聲 -20）→ **弱點 ×2** → **抵抗力 -30** → 防守方效果（鐵甲蛹堅硬身軀 -20、冰砌鵝冰塊頭）。
快龍V「撕裂」不受對手效果影響。
* **擲硬幣**：連續舞步、連環巴掌、寶可夢捕捉器、灼傷／睡眠檢查、混亂等，系統擲、紀錄裡看得到結果。
* **特殊狀態**：中毒（惡棍猛毒一次 40）、灼傷、睡眠、混亂、麻痺；芳香草能量免疫；進化、撤退會解除。
* **氣絕、獎賞卡**：V 寶可夢 2 張；拿完 6 張、對手場上沒寶可夢、對手牌庫抽不出來就分出勝負。
你的寶可夢氣絕時，照提示把卡放到棄牌區，再把備戰寶可夢移到戰鬥場，遊戲會自動繼續。
* 你的每一格會在相機畫面上標 **HP 剩餘／最大**，電腦的場面顯示在畫面上方。
* 需要選擇的招式（阿勃梭魯「拖出」選目標、優雅貓「愛管閒事」看電腦手牌）會跳出按鈕讓你選。

### 電腦怎麼想

每回合：找牌（先機球、超級球、寶可齒輪、草路競技場）→ 放基礎寶可夢、進化 → 把能量貼給「最快能打出招式」的寶可夢 →
挑最划算的支援者（手牌少就用博士的研究、對手剩 6/4/2 張獎賞卡用女學生…）→
戰鬥寶可夢打不好、備戰區有更強的就交替或撤退 → 能用寶可夢捕捉器拉出一隻打得倒的就拉 →
幫每個招式打分數（打得倒 > 傷害 > 特殊狀態等附加效果，扣掉反作用與龍之強風打到自己備戰區的代價）選最好的攻擊。
